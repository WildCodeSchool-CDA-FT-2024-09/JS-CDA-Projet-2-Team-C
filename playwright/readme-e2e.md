## End to End Testing Setup

    - Install "Playwright Test for VsCode" extension on VsCode
    - `cd /playwright` and `npm i`
    - Run `npx playwright install` to globally install the browsers used for tests
    - In the "testing" sidebar tab in Vscode, Playwright tests should show up
    - At the bottom of this sidebar Playwright can be configured
    - Check "Show browser" to see browser output / actions while tests run
